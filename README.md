## 🌊 Sobre el Proyecto
Ocean Graph es una plataforma diseñada para mostrar el poder de la narrativa visual. Enfocada en la creación de contenido profesional para redes sociales (especialmente Instagram), esta web sirve como portafolio interactivo y centro de comunidad para clientes que buscan elevar su marca al siguiente nivel. Profesional.

## ✨ Características Principales

*   **📱 Detección Inteligente de Dispositivos:** Experiencia optimizada y fluida que se adapta automáticamente si el usuario ingresa desde una PC, Tablet o Smartphone.
*   **📂 Portafolio Dinámico:** Sistema de filtrado por categorías (Salud, Belleza, Eventos, Deportes, etc.) alimentado por una base de datos JSON escalable.
*   **🎬 Experiencia Audiovisual:** Reproductor de video personalizado estilo "Reels/TikTok" para una visualización inmersiva en dispositivos móviles.
*   **👥 Hub de Comunidad:** Un espacio vivo con integración de publicaciones reales de Instagram y TikTok mediante carga perezosa (*lazy loading*) para un rendimiento ultra rápido.
*   **🌓 Dual Tone:** Soporte completo para Tema Oscuro y Tema Claro, respetando la preferencia del usuario.
